# Koder Claude Code Mods

Claude Code plugins built and maintained by [Koder SpA](https://koderspa.com).

![Cost Dashboard running in a Claude Code session](./cost-dashboard/docs/preview.png)

## Install

```
/plugin marketplace add Koder-SpA/claude-mods
```

Then install any plugin from the list below.

## Plugins

| Plugin | What it does |
|---|---|
| [`cost-dashboard`](./cost-dashboard) | Real-time token, cost, context and rate-limit dashboard in the statusline |
| [`task-router`](./task-router) | Delegates each sub-task to the right model and effort for your plan |

```
/plugin install cost-dashboard@koderspa
/plugin install task-router@koderspa
```
